# CO2-rSO2 Author and Submission Statements Template

Status: author-side template for final submission. This file prevents accidental reuse of unconfirmed author, ethics, funding, data, and competing-interest text from the prior MAP/CI manuscript.

## Confirm Before Submission

Fill these fields from the CO2 manuscript team, not by inference:

- Final author list and order
- Author affiliations and ORCID identifiers
- Corresponding author name, email, and postal address
- Institutional review board name
- Approval number and approval date
- Consent or waiver wording
- Funding source names and grant numbers, if any
- Competing-interest declarations from every author
- Author contribution roles
- Data availability pathway and access restrictions
- Code availability location and final commit hash
- Acknowledgements
